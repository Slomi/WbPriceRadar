# 📉 Мониторинг цен конкурентов на Wildberries

Telegram-бот для селлеров: следит за ценами и остатками ваших товаров и товаров конкурентов на WB и сразу сообщает, когда что-то изменилось.

## Возможности

- **Добавление по ссылке или артикулу**, можно сразу несколько. Товары делятся на «мои» и «конкуренты», конкуренты привязываются к своему товару
- **Автопроверка** каждый час (интервал настраивается), без ключей API и без VPN
- **Уведомления:** конкурент подешевел или подорожал, стал дешевле вас (и на сколько), закончился товар, снова появился, остаток меньше N штук
- **Утренняя сводка:** ваша цена, цены конкурентов, ваше место по цене, кто дешевле
- **График истории цен:** вы и конкуренты на одном графике. История есть с первого дня, её подгружает недельная история цен WB
- **Выгрузка в Excel:** текущие цены, скидки, разница с вашей ценой, остатки и вся история. Строки, где конкурент дешевле, подсвечены
- **Настройки прямо в боте:** порог уведомлений (любое изменение, 3, 5 или 10%), время сводки, порог «заканчивается»
- **Многопользовательский:** у каждого свой список. Доступ можно ограничить списком ID

## Стек

Python 3.11, aiogram 3, SQLite, curl_cffi (WB отсекает обычные HTTP-клиенты по TLS-отпечатку), matplotlib, openpyxl.

## Запуск

```bash
py -3.11 -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env      # впишите BOT_TOKEN
.venv\Scripts\python bot.py
```

## Ограничения

- Цены берутся из публичного API WB: это цена продавца со скидкой. Персональные скидки покупателя (WB-кошелёк) API не учитывает, поэтому на сайте цена может быть на несколько процентов ниже.
- Остатки показаны для выбранного региона доставки (`WB_DEST`, по умолчанию Москва).
- Ozon закрыт антибот-защитой, его можно добавить под конкретную задачу (через headless-браузер или Seller API для своих товаров). Модуль `wb.py` изолирован, так что второй маркетплейс подключается рядом.
