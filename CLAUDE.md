# Контекст проекта

Демо-бот №3 для портфолио фрилансера: мониторинг цен и остатков конкурентов на WB для селлеров. Демо №1 и №2 — в `../1`, `../2`.

## Устройство
Python 3.11, aiogram 3, SQLite.
- `wb.py` — публичный API WB: карточки `card.wb.ru/cards/v4/detail` (пачками по 100, `;` в URL не кодировать) и недельная история `basket-XX.wbbasket.ru/.../price-history.json` (номер basket ищется перебором и кэшируется по тому артикула). Только через `curl_cffi` с `impersonate="chrome"`: aiohttp получает 400, httpx 403
- `monitor.py` — проверка всех артикулов раз в `CHECK_INTERVAL_MIN`, уведомления, ежедневная сводка
- `reports.py` — карточка товара, сводка, график (matplotlib, без эмодзи в подписях), Excel
- `handlers/main.py` — всё UI: добавление (мои / конкуренты; привязка галочками — всем сразу или «по-разному для каждого»), список, карточка, «🔗 Привязка», настройки
- Конкурент ↔ мой товар — многие-ко-многим, таблица `links` (старый `products.parent_id` мигрируется в `db.init`)
- История общая для всех пользователей (таблица `history`, источник `wb` или `bot`). «За сутки / за 7 дней» считается только по точкам из окна [2d..d] назад
